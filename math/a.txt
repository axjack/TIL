学び：「内部・閉包・補集合の変換則」
====================
内部：
　int(A) = ⋃{ O| O open , O⊂A }
閉包：
　cl(A)  = ⋂{ F | F closed, A⊂F } 


包含の言い換え：
点の視点：
A⊂B ⇔ ∀x(x∈A ⇒ x∈B) ⇔∀x∈A, x∈B

集合の視点：
A⊂B ⇔  A\B =∅ ⇔ A⋂B‪ᶜ‬ =∅
　AはBに含まれる
　AからBを除外すると何も残らない
　AはBの外側と交わらない

A⊄B ⇔ A\B ≠∅ ⇔ A⋂B‪ᶜ‬ ≠∅
　AはBに含まれない
　AからBを除外すると残る
　AはBの外側と交わる

包含と補集合：
A⊂B ⇔ B‪ᶜ‬⊂A‪ᶜ‬


内部と閉包の双対関係：
( int(A) )‪ᶜ‬  =   cl(A‪ᶜ‬)
　内部の補集合は補集合の閉包に等しい
int(A‪ᶜ‬) = (cl(A))‪ᶜ‬
　補集合の内部(外部)は閉包の補集合に等しい

略証
(int(A))‪ᶜ‬ = ( ⋃{O | O open,  O⊂A } )‪ᶜ‬
= ⋂{ O‪ᶜ‬| O open, O⊂A} 
F := O‪ᶜ‬ for any O open
= ⋂{ F | F closed, A‪ᶜ‬⊂ F}
= cl(A‪ᶜ‬)

閉包 cl
・拡大的：A⊂cl(A)
・冪等的：cl(cl(A)) = cl(A)
・単調：A⊂B⇒cl(A)⊂cl(B)
・∅を固定：cl(∅)=∅

内部 int
・縮小的：int(A)⊂A
・冪等的：int(int(A)) = int(A)
・単調：A⊂B⇒int(A)⊂int(B)
・Xを固定：int(X) = X


境界を閉包で言い換え
∂A = cl(A) \ int(A)
       = cl(A) ∩ (int(A))‪ᶜ‬
　　= cl(A) ∩ cl(A‪ᶜ‬)
　境界はAの閉包とA‪ᶜ‬の閉包との交差


内部・近傍・閉包の言い換え1
a ∈ int(B) ⇔ B ∈ N(a) ⇔ a ∉ cl(B‪ᶜ‬)
　aはBの内部にある
　Bはaの近傍である
　Bの補集合の閉包にaは入らない

内部・近傍・閉包の言い換え2
a ∉ int(B) ⇔ B ∉ N(a) ⇔ a ∈ cl(B‪ᶜ‬)
　aはBの内部に入らない
　Bはaの近傍ではない
　Bの補集合の閉包にaが入る

内部と近傍
x∈int(A) ⇔∃U∈N(x) U⊂A
⇔ ∃Ox∈𝒪 x∈O⊂A
⇔ ∃Ox∈𝒪 x∈O かつ O⊂A
xを含む開集合がAの中に取れる

x∉int(A) ⇔¬(∃U∈N(x) U⊂A)
⇔ ∀U∈N(x) ¬(U∩A‪ᶜ‬=∅)
⇔ ∀U∈N(x) U∩A‪ᶜ‬≠∅
⇔ x∈cl(A‪ᶜ‬)

x∉int(A) ⇔ x∉⋃{O|O open, O⊂A}
⇔ x∈⋂{O‪ᶜ‬|O open, O⊂A}
⇔ x∈⋂{F | F closed, A‪ᶜ‬⊂F} ただしF:= O‪ᶜ‬
⇔ x∈cl(A‪ᶜ‬)

集積点
xがAの集積点とは
x∈cl(A\{x})
Aの集積点を全て集めた集合を導集合といい
d(A) = { x | x∈cl(A\{x}) }

定理：cl(A) = A∪d(A)
証明：
[⇒]
x∈cl(A)を任意にとる
x∈Aのとき
　x∈A ⇒ x∈A∪d(A)
x∉Aのとき
　A=A\{x}
　仮定よりx∈cl(A)=cl(A\{x})
　したがってx∈d(A)しかるにx∈A∪d(A)
以上より⇒は成り立つ。
[⇐]
x∈A∪d(A)を任意にとる
x∈Aのとき
　clの拡大性よりA ⊂ cl(A)
　よってx∈cl(A)
x∈d(A)のとき
　x∈d(A) ⇒ x∈cl(A\{x})
　A\{x}⊂Aからclの単調性より
　cl(A\{x}) ⊂ cl(A)
　よってx∈cl(A)
以上より⇐は成り立つ
双方の含意が成り立つため、
cl(A) = A ∪ d(A)∎
